# Web rules entrypoint

Scope: package `web`, `apps/web/**`. Trước khi sửa code, đọc các rule tương ứng tại root repository:

- [Architecture và export portals](../../.agent/rules/web-architecture.md)
- [TypeScript và control flow](../../.agent/rules/web-typescript.md)
- [UI, form và i18n](../../.agent/rules/web-ui-forms.md)
- [Query và mutation](../../.agent/rules/web-data.md)

Nội dung rules chỉ được duy trì trong `.agent/rules/*.md`; file này là điểm dẫn để agent tự tìm thấy rules. Không áp dụng chúng cho app/package khác ngoài scope được ghi trong từng file.
